### 3. Reward Computation

**Demo Notebook:**
```python
# Reward is MOSTLY RANDOM with minor adjustments
reward = 0.75 + len(result) * 0.03 + np.random.normal(0, 0.05)
#        ^^^^                         ^^^^^^^^^^^^^^^^^^^^^^^^^^^
#        Fixed baseline               Random noise dominates

# The +0.017 "improvement" is just random variation!
```

**Real Training Notebook:**
```python
def execute_sql_for_reward(sql: str, db_conn) -> Tuple[float, str, bool]:
    try:
        cursor = db_conn.cursor()
        cursor.execute(sql)  # Actually execute the generated SQL!
        results = cursor.fetchall()

        # Base reward for successful execution
        reward = 0.5

        # Bonus for returning results
        if results:
            reward += 0.3
            if 1 <= len(results) <= 20:
                reward += 0.2  # Good result count

        return reward, f"✓ {len(results)} rows", True

    except sqlite3.Error as e:
        # Real penalty for syntax errors
        if 'syntax' in str(e).lower():
            reward = -0.5
        return reward, f"✗ {str(e)}", False
```

**Why it matters:** Real rewards provide meaningful feedback. Random rewards can't guide improvement.
